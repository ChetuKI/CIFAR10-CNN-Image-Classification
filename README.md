# CNN for CIFAR-10

A **Convolutional Neural Network (CNN)** built using **PyTorch** for image classification on the **CIFAR-10 dataset**.

### 🛠️ Technologies
- Python
- PyTorch
- Torchvision
- CNN

### 📊 Dataset
CIFAR-10 contains **60,000 RGB images (32×32)** belonging to **10 different classes**.

### 🧠 Model
The CNN uses:
- Convolutional layers
- ReLU activation
- Max Pooling
- Fully Connected layers

### 🎯 Objective
To build and train a CNN model capable of classifying CIFAR-10 images into their respective categories.

### ▶️ Run
Open `CNN_for_CIFAR10.ipynb` in **Jupyter Notebook / JupyterLab / Google Colab** and run the cells sequentially.
